# HINA PIANO FEEDBACK

稲積陽菜による演奏動画フィードバックサービスの、スマートフォン対応ランディングページです。Node.js 24で動作確認済み。外部パッケージのインストールは不要です。

## 起動

```sh
cd /workspace/piano-feedback
npm run dev
```

既定ポートは3000。`PORT=別のポート npm run dev`で変更できます。JavaScriptの構文チェックは`npm run check`。

## 運用設定

`config.js`でブランド名、料金、返信日数、キャンペーン表示、プロフィール・受賞歴、本人写真、保存期間、メンバーシップ表示を変更できます。

- 各プランとキャンペーンの`squareUrl`にSquare決済リンクを設定してください。オプションは画面上の見積りで、Square側にも同じ商品・オプションを用意する必要があります。Squareの決済後遷移先をサイトの`/#submit`に設定します。
- `dropboxUrl`にDropbox File Request URLを設定します。
- `formEndpoint`にJSON POSTを受け付けるHTTPSの申込受付APIを設定します。異なるドメインではCORS設定が必要です。現時点で受付APIは含まれません。運用時はサーバー側の入力検証、決済照合、メール送信、保存・削除、迷惑送信対策を実装してください。フロントエンドのチェックだけでは支払い済みであることを確認できません。
- 接続先未設定時は受付準備中と表示し、決済・送信成功を装いません。入力内容はブラウザのメモリのみで扱い、ローカルストレージには保存しません。
- キャンペーンの先着人数は告知表示で、自動在庫管理ではありません。Square側で受付数を管理してください。
- 正式公開前にキャンセル・返金条件、個人情報保管期間、正式プロフィール、利用規約、プライバシーポリシー、特定商取引法に基づく表記、運営者連絡先を確定してください。

`assets/piano.png`はサイト用に生成したピアノのイメージ写真です。本人の写真ではありません。`profilePhoto`に正式な写真のパスを設定するとプロフィール写真の掲載予定表示が消えます。

## 構成

`index.html`（ページ）、`style.css`（レスポンシブ表示）、`app.js`（料金・FAQ・フォーム）、`config.js`（編集用設定）、`server.js`（開発用静的サーバー）。静的ホスティングへ配置可能です。本番環境では専用のWebサーバー・HTTPSを使用してください。

## 確認用テスト公開

`previewMode: true` によって決済、Dropboxへの遷移、フォームのネットワーク送信を強制的に無効化しています。外部リンクが将来設定されても、確認モードの間は無効です。検索エンジンにはnoindexを指定していますが、アクセス制限ではありません。正式公開には各運用設定、規約の確定とpreviewModeの見直しが必要です。
